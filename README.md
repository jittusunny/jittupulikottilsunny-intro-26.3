## Open API Project

The Open API project is a Weather Explorer that uses the Open-Meteo API.

Users can:
- Select a city
- View the current temperature
- View the current weather conditions

The project uses two separate GET requests:
- Temperature data
- Weather condition data

## How to Run

1. Clone or download the repository.
2. Open the project folder in VS Code.
3. Open `index.html` in a web browser.
4. Click **My OpenAPI Project** in the navigation bar.
5. Select a city.
6. Click **Temperature** or **Conditions** to view the weather information.
